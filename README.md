# Sneak Peek

A [Balatro](https://www.playbalatro.com/) mod that adds a Joker showing
the next card of your deck.

## Features

- **Sneak Peek** (Uncommon Joker): displays the next card to be drawn.

## Requirements

- [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector)
- [Steamodded](https://github.com/Steamodded/smods)

## Installation

1. Install Lovely and Steamodded following their instructions.
2. Copy the `sneakpeek` folder into `%AppData%\Balatro\Mods\`.
3. Launch the game and check the **Mods** menu.
